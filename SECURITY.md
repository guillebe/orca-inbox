# Security policy

Inbox types text into your terminals and runs as a trusted worker with your user's access, so we
take security reports seriously.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead: **Security → Report a
vulnerability** on this repository. Include what an attacker could do, the steps to reproduce, and
the Orca and plugin versions.

You will get an answer within a week. Fixes ship in a new release, and the advisory credits you
unless you prefer otherwise.

## Scope

In scope: anything that makes the plugin type text you did not send, answer a terminal prompt on
your behalf, reach data outside its own storage, or run commands other than `orca terminal switch`.
